# まなび Test Maker

数学教員向け定期考査作成・問題管理Webアプリ。v0.2.0 開発版。

## 起動

静的サイトです。GitHub Pages の Settings → Pages → Deploy from a branch → main / (root) を設定すると利用できます。ローカルでは `python -m http.server 8000` をリポジトリ直下で実行し、http://localhost:8000 を開きます。ビルド不要、外部API不要。

## 初期機能

問題保管庫、サンプルMathML・SVG、問題追加・自由配置（mm）、配点と観点集計、重なり警告、端末内自動保存、最大30件の履歴、暗号化バックアップ、ブラウザ印刷/PDF。

## 数学図形の方針

AIの画像をそのまま使わず、座標と明示条件からSVGを生成する。AB=ACは1本線、BD=DCは2本線、ADは無印。別グループで記号を使い回さず、余計な条件を追加しない。geometry.mjs の等長グループ検証を導入した。一次関数の例は y=x+1。

## 検証

Node.js 18以上で `node --test tests/geometry.test.mjs`。ブラウザでの操作・印刷は別途確認する。

## v0.2.0 保管庫
- HTTPSのWeb Crypto APIを使用。PBKDF2-SHA256 600,000回、16バイトランダムsalt、AES-256-GCM、暗号化ごとに12バイトのランダムIV。鍵はメモリのみ。
- IndexedDBに暗号化データを保存。旧版の平文localStorageは移行成功後に削除。古いバックアップやブラウザの物理的残留データまでは消去できない。
- 編集直後に暗号化保存を順次実行。保存中・失敗を表示。タブを閉じる前は保存済みを確認。別タブの更新はリビジョン比較で上書き防止。15分無操作でロック（保存失敗時はデータ保護のため中止）。
- 別端末では保管庫を作成し、.manabitestファイルを読み込み、元のパスフレーズを入力。現端末のパスフレーズで再暗号化。復元前に暗号化バックアップを出力。
- パスフレーズの復旧機能はない。十分長く推測困難なものを設定し、安全な場所に保管する。ブラウザデータ消去や端末障害に備えてバックアップする。
- アプリ配信元の改ざんや端末感染、アンロック中の覗き見、PDF出力後のファイルは保護範囲外。Drive自動同期はまだ未実装。
